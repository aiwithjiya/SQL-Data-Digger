# 🛒 ShopDB SQL Project

This project demonstrates the implementation of **CRUD operations (Create, Read, Update, Delete)** using SQL. It includes a simple **Shop Database system** with multiple related tables.

---

## 📌 Project Overview

The database **ShopDB** contains the following tables:

* 👤 Customers
* 📦 Orders
* 🛍️ Products
* 📄 OrderDetails

Each table is designed to simulate real-world e-commerce operations.

---

## ⚙️ Features

* ✔️ Create database and tables
* ✔️ Insert sample data
* ✔️ Perform CRUD operations
* ✔️ Apply filtering and sorting
* ✔️ Use aggregate functions (SUM, AVG, MAX, MIN)
* ✔️ Grouping and analysis queries

---

## 🗂️ Database Structure

### 1. Customers Table

Stores customer details like name, email, and address.

### 2. Orders Table

Tracks customer orders with date and total amount.

### 3. Products Table

Contains product details like price and stock.

### 4. OrderDetails Table

Stores order-wise product details and subtotal.

---

## 🔄 CRUD Operations

### ➤ Create

* Database and tables created using `CREATE` statements
* Data inserted using `INSERT INTO`

### ➤ Read

* Retrieve data using `SELECT`
* Filtering using `WHERE`
* Sorting using `ORDER BY`

### ➤ Update

* Modify records using `UPDATE`

### ➤ Delete

* Remove records using `DELETE`

---

## 📊 Sample Queries

* Get all customers
* Find orders of a specific customer
* Update product price
* Delete out-of-stock products
* Calculate total revenue
* Find top ordered products

---

## 📈 Advanced Queries Used

* Aggregate functions: `MAX()`, `MIN()`, `AVG()`, `SUM()`
* Grouping: `GROUP BY`
* Filtering: `WHERE`, `BETWEEN`
* Date operations: `CURDATE()`
* Sorting: `ORDER BY`
* Limiting results: `LIMIT`

4. View outputs using `SELECT` queries
